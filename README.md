# silver-memory

## Propósito
Este repositorio tiene como propósito aprender a utilizar GitHub para almacenar, organizar y versionar archivos de código.

## Descripción
En este repositorio se encuentra el archivo `hola_mundo.html`, que contiene un código HTML sencillo. El archivo ha sido subido a GitHub y posteriormente modificado para comprobar el funcionamiento del historial de versiones y los commits.
